# 好好衡量 · BMI 計算機

繁體中文、響應式靜態網頁。開啟 `index.html` 即可使用，不需要安裝套件或後端。

也可以在專案目錄執行 `python3 -m http.server 8000`，瀏覽 http://localhost:8000。

支援即時計算、數值驗證、清空輸入、體位分類與依身高計算的健康體重參考區間。字型載入使用 Google Fonts，離線時改用系統字型。

可選擇測量日期並按「儲存本次紀錄」，將身高、體重及日期保存在此瀏覽器的 localStorage（最多 500 筆），不傳送至伺服器。重新開啟時帶入最近儲存的身高、體重；輸入中的數據不會自動儲存。同日同數值會防止重複儲存。可逐筆刪除或確認後清空全部。

BMI 趨勢圖顯示依測量日期排序的最近 30 筆紀錄，每筆等距排列，不表示日期間隔；表格提供全部紀錄。健康體位參考帶為 18.5 ≤ BMI <24。圖表不依賴第三方圖表服務。

紀錄僅限目前瀏覽器與網站來源，不跨裝置同步；清除網站資料後無法復原。不同連接埠、網址或直接開啟檔案的儲存空間可能不同。儲存不可用、空間不足或既有資料損壞時，介面會提示失敗，不會顯示成功或直接覆寫損壞資料。

公式：BMI = 體重 kg ÷ (身高 cm / 100)²。分類使用未四捨五入的 BMI，畫面顯示小數一位。

驗證：`node --test tests/history.test.cjs`，涵蓋恢復紀錄、損壞資料、儲存失敗、清空、重複紀錄與圖表筆數限制。

採用[國健署成人健康體位標準](https://www.hpa.gov.tw/542/9737/n)：過輕 <18.5、健康 18.5–<24、過重 24–<27、肥胖 ≥27。適用於 18 歲以上成人；結果僅供參考。
